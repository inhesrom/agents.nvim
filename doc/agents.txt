==============================================================================
OVERVIEW                                                  *agents.nvim-overview*

agents.nvim is a zero-config, dependency-free plugin for launching configured
CLI agents from Neovim. Version 1 is terminal-session-first: it wraps generic
interactive CLIs in managed terminal sessions.

The built-in `codex` and `claude` agents are registered automatically only when
their executables are found on PATH.

Official support targets Neovim 0.12+. Neovim 0.11 is best-effort where the
required APIs are available.

==============================================================================
COMMANDS                                                  *agents.nvim-commands*

:Agents launch [name]                                      *:Agents-launch*
        Launch a new Agent Session. Without [name], opens the agent picker.

:Agents sessions                                           *:Agents-sessions*
        Open the global session picker, sorted by most recent use.

:Agents hide                                               *:Agents-hide*
        Hide the current Agent Session window without stopping its terminal job.

:Agents send                                               *:Agents-send*
        Resend the stored task prompt to the current running Agent Session.

==============================================================================
LUA API                                                        *agents.nvim-api*
>
  require("agents").setup(opts)
  require("agents").launch(name?)
  require("agents").sessions()
  require("agents").hide()
  require("agents").send(session_or_id?)
<

==============================================================================
CONFIGURATION                                    *agents.nvim-configuration*
>
  require("agents").setup({
    default_keymaps = false,
    keymaps = {
      launch = "<leader>aa",
      sessions = "<leader>as",
    },
    ui = {
      width = 0.85,
      height = 0.85,
      snap = {
        width = 0.40,
        height = 0.35,
      },
    },
    agents = {
      codex = {
        cmd = "codex",
        args = {},
      },
      claude = false,
      custom = {
        cmd = "my-agent",
        args = { "--interactive" },
        send = {
          ready = "output-idle",
          ready_idle_ms = 250,
          ready_timeout_ms = 3000,
          delay_ms = 80,
          bracketed_paste = true,
          submit = true,
        },
      },
    },
  })
<

No keymaps are installed by default. Set `default_keymaps = true` to map:

  `<leader>aa`  launch an agent
  `<leader>as`  open sessions

Agent specs accept `cmd` or `command`, optional `args`, and optional `send`
settings.

`ui.width` and `ui.height` control the centered Agent Session float. `ui.snap`
controls real split size when snapping: `width` applies to left/right splits and
`height` applies to top/bottom splits. Values below 1 are fractions of the anchor
editor window; values 1 or above are cells.

`send.ready` controls when the task prompt is pasted into the terminal:

  `"output-idle"`  wait for visible terminal output to stop changing
  `"delay"`        preserve delay-only scheduling

With `"output-idle"`, `send.ready_idle_ms` is the stable-output wait and
`send.ready_timeout_ms` sends anyway if no stable output is detected. `delay_ms`
is applied after readiness. `send.submit` may be `true`, `false`, `"enter"`, or
`"newline"`.

==============================================================================
SESSION MODEL                                      *agents.nvim-session-model*

Every launch creates a new Agent Session. The plugin captures the current Git
root, falling back to Neovim's cwd, plus a project-relative file path and line
or range.

The task editor opens with:
>
  Task:

  Context:
  File: path/to/file.lua
  Range: lines 10-20
<

Press `<CR>` in normal mode to submit. Press `q` or `<Esc>` to cancel. The
first non-empty line after `Task:` becomes the session description. If it is
empty, the target label is used.

Agent terminals open in centered bordered floats. Press `s` in normal mode to
enter snap mode. Then press `h`, `l`, `j`, or `k` to move the same Agent Session
buffer into a real split on the left, right, bottom, or top of the last focused
editor window. Press `f` in snap mode to restore a centered float, or `q`/`<Esc>`
to cancel snap mode. Outside snap mode, press `q` or `<Esc>` in normal mode to
hide the current session window. Centered floats show keybind hints in their
native float footer; snapped splits show a centered, muted Session Hint Line
attached to the bottom of the session pane. The snapped line uses the
`AgentsSessionHint` highlight, linked to `Comment` by default. The terminal job
keeps running. Hidden sessions notify when their process exits.

The submitted task prompt is stored on the session. Use `:Agents send` or
`require("agents").send(session_or_id?)` to resend it immediately if a terminal
CLI drops startup input or needs manual retry.

The session picker includes live and exited sessions. Press `<CR>` to show a
session. Press `d` to delete an exited session immediately; deleting a live
session asks for confirmation before stopping the job.
